# AA Transcribe — webpage

Atelier Astil's transcription webpage. Open https://atelier-astil.github.io/AA-TRANSCRIBE-WEB/ in Chrome or Edge.

- Speech recognition runs inside the browser with the open-source Whisper model. Recordings and transcripts stay on the device that made them.
- The first transcription downloads the speech model once (250 MB to 1 GB). After that it starts immediately.
- Keep the page open while a file is transcribing. Export transcripts to share them.

Source and the installable edition are maintained in the studio's private AA-TRANSCRIBE repository.
